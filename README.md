# Employee Dashboard

A responsive React assignment built with Vite, React Router and CSS.

## Features
- Navbar with Home and Employee Form routes
- Fetches users from `https://jsonplaceholder.typicode.com/users`
- Displays employee ID, name and email in a table
- Employee form with Name, Designation, Location and Salary
- Responsive layout for mobile and desktop
- Does not send form data to a backend

## Run locally
1. Install Node.js.
2. Open a terminal in this folder.
3. Run `npm install`
4. Run `npm run dev`
5. Open the local URL shown by Vite.

## Routes
- `/` — Employee Dashboard
- `/employee-form` — Employee Form

## Technologies
React, Vite, React Router DOM, Fetch API, CSS.
